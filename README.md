# Feishu Doc MCP

A Model Context Protocol (MCP) server for accessing Feishu Open Platform documentation.

## Features

- Search Feishu API documentation by category
- Read detailed documentation content
- Support for multiple API categories (Server API, Client API, Development Guides, etc.)

## Installation

```bash
npm install
```

## Usage

This MCP server provides tools to search and read Feishu Open Platform documentation.
